## 2. Design System & Aesthetic Language
- **Inspiration**: Reference craft from `deepakkk.com` adapted into an authentic BORA identity.
- **Palette**:
  - **Noir**: `#000000` (60% Dominant canvas)
  - **Ivory**: `#F4F0E8` (30% High-legibility typography & structural lines)
  - **Champagne**: `#C9B79C` (10% High-intent focal accent)
  - **Anthracite**: `#272727` (Card frames, hairline dividers, subtle states)
- **Typography**:
  - Display & Headings: *Plus Jakarta Sans* (bold, geometric, `-0.03em` tracking)
  - Editorial Accents: *Playfair Display* (luxury monograph aesthetic)
  - Monospace Data / Code: *JetBrains Mono* (`tabular-nums`)
- **Anti-Slop Restraints**:
  - Zero static pill boxes or colored candy capsules for metadata.
  - Zero mechanical code comments (`// 01`) or fake version tickers ("SYNTHEX v4").
  - Clean unboxed metadata with `·` typographic separators.
  - Single-line controls with strict 3-zone header contract.
  - Strict WCAG AA contrast compliance and touch targets >= 44px on mobile.

## 3. Signature Features
1. **Interactive Dotted Portrait & Particle Physics Engine**:
   - Canvas 2D multi-particle system with rest coordinates forming a realistic portrait.
   - Dynamic spring recovery, pointer repulsion, velocity-based swirl vectors, click shockwave.
   - Automatic frame rate detection with adaptive particle density.
   - Reduced-motion static halftone rendering.
   - Built-in interactive Portrait Studio uploader allowing custom image rasterization to dot matrices.
2. **Deep Project Case Studies**:
   - **Atelier Noir**: Premium fashion e-commerce platform.
   - **LogixCore ERP**: Enterprise supply-chain & logistics operational platform.
   - Complete technical breakdowns: Overview, Problem, Scope, Actual Role, Design Decisions, Engineering Approach, Implemented Features, Challenges & Solutions, Verified Outcomes.
3. **Full-Stack Contact Engine**:
   - Server-side Express Route Handler (`POST /api/contact`) with rate limiting, anti-spam honeypot, field validation, and Resend provider support with working mailto fallback.
